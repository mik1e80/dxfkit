# dxfkit 开发版维护进度

本轮对应顾问计划中的安全、诊断、R12 字段、编码、几何和供应链。当前为未发布的 0.2.0 开发版，已发布 0.1.1 和历史网页演示各有对应源码。

| 方向 | 本轮交付 | 后续范围 |
| --- | --- | --- |
| 安全 | SVG UTF-8 字节预算、XML 字符处理、数值非法字节拒绝、固定种子回归，CI 以独立进程限制验证线段大图 | 更多结构、曲线和复杂块变异，服务部署环境的资源实测 |
| 诊断 | 稳定检查类别、级别与状态，保留旧 Report 和 CLI 文本 | 逐条读取阶段、展开阶段、来源与资源消耗 |
| R12 | 审计部分常用单值字段、INSERT 本地块引用及已声明的 LAYER/LTYPE/STYLE 引用 | 全部表记录与句柄关联、ATTRIB/ATTDEF 布局、三维/网格、SHAPE、VIEWPORT 和标注 |
| 编码 | ANSI_936 双字节解码和可信回调，UTF-8/GBK 坏字节进入报告 | CLI/Web 默认未内置 932、949、950 |
| 几何 | 独立曲线、平面、比较容差。按图层归集端点和线段，自交、重叠和净距共用排序索引。竖直端点筛选有候选预算断言 | 极密集图纸上的空间索引和更多近退化真值 |
| 供应链和许可 | Actions 固定提交。映射表保留版权、许可及生成来源 | 新版本的完整验收与 registry 消费 |
| 模型 | 重放真实 CAD 和独立预期，新增 [FreeCAD 空间圆导出反例](../examples/cad-ocs/README.md)，记录 1 千至 10 万线段运行成本 | 更多实际 CAD 来源、有非默认 OCS/MINSERT 的原生导出、整图独立真值 |

## 本地验证

受影响的解析、编码、几何和安全用例分批运行。既有定向集中的 120 项 R12/几何回归、Wasm 和 JS 各 26 项安全与编码相关回归、14 项语料断言、十类参数模型、CLI 和网页回归通过。47 份第三方语料的观察记录保持不变，审计仅更新源码指纹。

独立 Wasm 消费工程 8/8 通过，几何测试敏感性检查 10/10 通过。空间圆案例记录 71 个世界点，报告拒绝完整二维检查。开发版打包预检通过，压缩包包含项目 LICENSE、第三方声明、WHATWG 许可和 CAD 原件。当前代码未执行整仓库四后端全量运行。
