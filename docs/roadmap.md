## 保留的边界

- 47 张第三方图纸仍是分层读取/解码回归，独立逐图纸几何真值为 0/47；新增真值须按文件记录，不能用字段对照数量替代。
- HATCH、非默认 OCS、闭合/周期 SPLINE 等未完整支持的语义继续报告检查不完整；没有承诺实现完整 DXF 标准或 CAM 加工决策。
- `bounds()` 的原始字段包围估计不替代 checked 验证，本轮没有新增 `bounds_checked()`。

## Issues 的使用方式

截至核对日期，GitHub Issues 列表为空；上面的待办仅在本页跟踪，没有伪造已创建的 issue、负责人或完成日期。可在 [Issues](https://github.com/mik1e80/dxfkit/issues) 查看后续问题。

报告问题时请提供：源码提交/模块版本、运行环境和命令、可分发的最小 DXF、预期结果及依据、实际报告和退出码。图纸来源与许可需要可说明；不方便公开的图纸可改为保留问题的最小输入。实施时先复现，再修改，并运行受影响测试；日常采用[轻量验证约定](verification-guide.md)，只有明确的最终验收才手动运行 full。
