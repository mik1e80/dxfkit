# 实体能力分层矩阵

核对日期：2026-10-22。本表描述本次交付子集；字段细节以[交付范围](delivery-scope.md)为准。所有行都可保留 ASCII Record 和类型身份；“可读取”不表示字段全部解码。损坏记录可能只有原始记录，没有有效 Geometry。

几何检查列中的“轮廓检查”指：退化、同图层端点闭合、单实体非相邻段真交叉、共线重叠和指定净距；各检查有适用条件，不意味着每种实体均会触发每项。净距只比较同图层不同实体；`min_gap=0` 关闭该项。非默认 OCS 的普通实体可能仍有 XY 投影，但必须报告检查不完整，不能据此验证其空间几何。

| 实体类型 | 记录读取 | 语义解码 | 离散/预览 | 参与检查 | 未承诺字段或语义 |
| --- | --- | --- | --- | --- | --- |
| LINE | 是 | 两端 XYZ，公共身份 | XY 线段 | 轮廓检查 | 厚度、完整线型、空间线段关系 |
| CIRCLE | 是 | 圆心 XYZ、半径 | XY 整圆折线 | 轮廓检查及非正半径 | OCS 转换、厚度、三维圆 |
| ARC | 是 | 圆心、半径、起止角 | XY 逆时针圆弧 | 轮廓检查及非正半径 | OCS 转换、通用三维圆弧 |
| ELLIPSE | 是 | 圆心、相对长轴向量、轴比、参数范围 | XY 椭圆/椭圆弧 | 轮廓检查 | 任意空间平面和完整挤出语义 |
| LWPOLYLINE | 是 | XY、标高、bulge、闭合位、声明顶点数 | 中心线，含 bulge 弧 | 轮廓检查；缺坐标则拒绝整条并诊断 | 宽度区域、OCS 转换；数量不符时仅带警告恢复 |
| 普通二维 POLYLINE / VERTEX / SEQEND | 是 | 顶点 XYZ、bulge、普通闭合/线型生成位 | XY 中心线 | 轮廓检查；损坏顶点拒绝整条 | 拟合、空间、网格/多面网格变体及完整顶点标志 |
| SPLINE | 是 | 次数、节点、控制点、权重 | 连续 B 样条及正权重 NURBS 的 checked XY 折线 | 成功离散后参与轮廓检查；失败报告原因 | 仅拟合点重建、完整闭合/周期语义、非正权重、无限资源 |
| SOLID / TRACE | 是 | 保留原始角点顺序 | **Entity** 接口按 0→1→3→2 连接，重复第四点仅输出一次 | 默认 OCS、零厚度、同 Z 角点的边界参与轮廓检查 | 非平行 XY、非零厚度、OCS 转换、填充区域；裸 Geometry::Face 不推断边界 |
| INSERT | 是 | 块名、插入点、缩放、旋转、行列数等 | 普通单实例 XY 展开、图层 0 继承、有限嵌套 | 展开后的受支持子轮廓；缺块/循环/截断等诊断 | 非默认 OCS 整个引用拒绝；阵列仅首实例，其他实例未检查；最多 8 层 |
| POINT | 是 | 点 XYZ | Dot 点预览，没有折线 | 点/图层相关提示；不作为闭合轮廓 | 点到轮廓净距、钻孔/加工语义；仅点文件报告无可检查轮廓 |
| TEXT / MTEXT / ATTRIB / ATTDEF | 是 | 已有文本、位置、字高、旋转等字段 | Label 简化预览 | 文字未转曲线及图层提示；不检查字形边界 | 字体转轮廓、完整排版、字形几何 |
| HATCH | 是 | 位置、solid/pattern/path 数等现有元数据 | 不重建边界 | 覆盖提示，检查不完整 | 填充路径、关联边界、图案重建 |
| DIMENSION 及现有相关标注分支 | 是 | 位置、块名、measurement 等现有元数据 | 不重建关联几何 | 覆盖提示，检查不完整 | 完整标注、匿名块呈现、关联约束 |
| 3DFACE | 是 | WCS 原始角点，不套用面边界重排 | 无检查/SVG 轮廓 | 覆盖提示，检查不完整 | 三维面、填充和边界推断 |
| RAY、其他未知实体、未支持 POLYLINE 变体 | 是 | 保留类型及原始 Record；不承诺几何解码 | 无承诺 | 覆盖提示，检查不完整 | 对应实体的完整字段与几何语义 |

公共字段包括图层 8、句柄 5（相关记录可用 105）、原始记录等；保留原始组码不等于解释其全部意义。所有受支持实体仍受输入诊断、容差、数值尺度和资源上限限制，具体组码及失败策略见[字段矩阵](delivery-scope.md#实体与字段矩阵)。
