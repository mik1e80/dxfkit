# 当前开发版的兼容性边界

本文描述未发布0.2.0源码；已发布0.1.1及历史Pages的能力以其原版本为准。详细字段见[R12范围矩阵](r12-profile.md)，分层验收见[符合性清单](r12-conformance-matrix.md)。

| 层次 | 当前可用行为 | 尚未承诺的内容 |
| --- | --- | --- |
| 文件与原始记录 | ASCII DXF，AC1009选择R12配置；源字节保留，预算范围内的有序tag/记录保留 | Binary DXF、DWG、写回；预算截断后记录不完整；不等于全部R12必填字段和关联约束符合 |
| 编码 | UTF-8、CP1252、ANSI_936 的 GBK 双字节映射。未内置代码页可传解码器，默认保留源字节并降级告警 | CLI/网页未内置 932/949/950。ANSI_936 不包括 GB18030 四字节扩展，编码声明限前 1024 字节 |
| 坐标/块 | 适用实体OCS→WCS、XYZ、块基点/缩放/旋转/全部阵列实例/有限嵌套、来源链 | 无限实例或深度、外部参照加载、完整 ATTRIB 字形和排版 |
| R12 实体与关联数据 | `r12_semantics()` 提供空间拓扑、符号和视口参数、标注图块、样式及覆盖关联、按阵列单元计算属性位置和已存拟合网格拓扑。字段审计覆盖部分表名和本地 XDATA 句柄 | 外部参照与 SHX 加载、尺寸编辑联动、从控制框重拟合曲面 |
| 二维几何 | 已重建且处于WCS Z=0容差内的轮廓；非默认OCS不再一律跳过 | 任意平面投影、空间网格参与二维验算、字形/标注/视口重建；非零宽度仅中心线不代表区域验证 |
| 曲线扩展 | LWPOLYLINE、ELLIPSE、受限SPLINE作为非R12扩展 | 闭合/周期SPLINE、所有结点/权重范围与精确几何；checked可能拒绝不安全数值 |
| 检查 | 退化、同图层端点拓扑、单实体自交、重叠及所选净距；未覆盖内容明确诊断 | min_gap=0不查净距；不同图层不互查净距，不查单实体窄颈；不作CAM/可加工性保证 |
| 原始bounds/宽松接口 | 提供原始字段估计及兼容调用 | bounds不是checked认证；Geometry局部入口不代替Entity的坐标语义处理 |
| 资源和平台 | 读取、展开、候选、渲染限制见[资源说明](resource-limits.md) | 固定峰值内存/时延、所有不可信输入无漏洞保证、未经实跑的平台兼容性 |

`Report::has_incomplete_checks()`为真时不得把普通退出0当完整检查；严格模式将警告作为失败。读取诊断、几何问题和资源耗尽都要由调用方保留。单位和阈值使用原图单位，不自动换算毫米；未声明单位不能补成毫米。

未来旧代码页、关联语义与完整标准验证必须有实现和独立预期后再更新能力矩阵；不能通过删除限制说明或改版本标题宣称完成。
