# dxfkit｜2026 年八月黑客松项目说明

**项目：** MoonBit ASCII DXF R12 记录读取与二维轮廓辅助检查库；[公开源码](https://github.com/mik1e80/dxfkit)，Apache-2.0。本文为仓库内的申报说明草稿，不表示已经报名或获得补交资格。

## 已有基础
已有 Mooncakes [0.1.1](https://mooncakes.io/docs/mik1e80/dxfkit)、实体解码与轮廓检查 API、CLI/SVG、独立消费示例、测试和 CI。当前源码为未发布的 0.2.0 开发版；新增 API 与安全防护不能用旧发布版或历史 Pages 演示替代验证。

## 本次新增成果与技术路线
在已有库上新增预算范围内的 R12/AC1009 源字节及有序记录保留、结构诊断、OCS→WCS、INSERT 全行列展开与来源链；统一检查不完整诊断，增加读取/几何资源预算及网页 Worker。流程为字节→Tag/RawRecord/Drawing→实体与世界坐标→适用的二维轮廓→Report/SVG。以上是截至 2026-11-14 的实际开发成果，不冒充在八月报名期限内完成；计入活动的工作范围由主办方确认。

## 目标与功能边界
为其他 MoonBit 程序提供可复用的图纸导入、预览和人工复核接口。检查范围限已重建、落在 WCS Z=0 容差内的二维轮廓；未支持语义、损坏输入或预算截断进入报告，strict 可失败。记录保留不等于完整 R12 符合性；旧中文代码页仍降级解码。不提供 DWG、写回、刀路或可加工性认证，详见[范围矩阵](r12-profile.md)和[安全边界](../SECURITY.md)。

## 测试与文档交付
已有[六份坐标/阵列设计对照](../examples/r12-validation/README.md)、[第三方语料分层记录](corpus-validation.md)及[FreeCAD 原生 R12 导出](../examples/cad-r12/README.md)：两个正常案例和一个预期未闭合告警案例，不称为三张正常图全部通过。保留模型、来源/许可/哈希、实际结果和重放命令；README、API 文档与[独立消费工程](../examples/consumer/README.md)说明使用方法。当前 CI 为定向验证，不能宣称已完成当前版本的整仓库验收。
