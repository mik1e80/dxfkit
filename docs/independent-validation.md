# 独立正确性对照及误差

后续 main 修订已实跑 [ezdxf 1.4.4 的五文件字段交叉核对](../examples/independent-fields/README.md)：67 条记录、507 个数值字段最大绝对差 0。仅比较列明字段，不是外部几何真值或新 CAD 导出；下面“本轮没有执行”指原始解析几何证据采集轮次，不代表此后仍未实跑字段对照。

这里的“独立”指预期值来自解析几何公式、另写的 Node 距离计算或不同求值算法，不由被测的生产离散器和包围盒函数生成。不是外部机构认证。本轮没有执行 Python ezdxf 几何对照，47 个第三方文件仍没有逐文件独立几何真值。

## 可保存和复算的解析对照

运行 `node scripts/verify-submission-evidence.cjs` 会读取 DXF，经实际 CLI 生成 SVG，再由 Node 解析 SVG 点列并检查。公式与点到线段投影单独写在该脚本，不导入 MoonBit 几何辅助函数。脚本版本用[结果 JSON](submission-evidence/results.json)中的 `oracle.script_sha256_lf` 标识；公式本身无软件版本号。MoonBit 发行包固定为 `0.10.14+7d59c7ec9`，本地 Node 为 24.19.0；每次实跑版本、提交及 dirty 状态另写 `_build/submission-evidence.json`。

| 对照对象 | 独立预期与指标 | 本次实际值 | 允许误差/判定 |
| --- | --- | --- | --- |
| 100×60 板件 | 外框坐标 (0,0)/(100,0)/(100,60)/(0,60)，鞋带面积、欧氏周长 | 四点逐项相等；面积 6000、周长 320 | 面积/周长绝对误差 ≤1e-10 |
| 四个半径 3 的圆孔轮廓 | 圆心 (10,10)/(90,10)/(90,50)/(10,50)，逐点半径及每弦中点弦高 | 最大半径误差 7.1054273576e-15；最大弦高 0.00972807559738 | 半径 ≤1e-10；弦高 ≤0.01+1e-10 |
| 旋转椭圆 | x=10+3cos(a)−2sin(a)，y=20+4cos(a)+1.5sin(a)；局部轴椭圆方程 | 方程最大残差 5.3290705182e-15；解析采样→SVG 最大距离 0.000978127563107；SVG 顶点→参考采样折线 0.00000583543644606 | 方程残差 ≤1e-10；双向距离 ≤0.002+1e-9 |
| 三次 S 形样条 | Bernstein 展开 x=3t²−2t³，y=3t(1−t)(1−2t) | 解析采样→SVG 最大距离 0.00143712816901；SVG 顶点→参考采样折线 0 | 双向距离 ≤0.002+1e-9 |
| 板件净距 | 圆心距最近外框 10，减半径 3 得 7；阈值 8 应报警，0.5 不报警 | 8 时报告 4 对实体、最小折线距离 7；0.5 时无发现 | 分类、4 对及距离文本断言；边界等值行为另由成对库测试验证 |

椭圆和样条均取 2049 个均匀参数参考点，并反查每个输出顶点到参考采样折线的距离。有限采样不构成连续 Hausdorff 误差证明；0 的反向距离仅表示该次点列与采样网格吻合。所有指标使用原始坐标单位；JSON 只将显示数值保留 12 位有效数字，断言使用未舍入 Double。SVG 文件保留实际输出，不因显示精度而改写。

## 现有库测试的独立性和边界

[`geometry_accuracy_wbtest.mbt`](../geometry_accuracy_wbtest.mbt) 的 9 类验收从 DXF 开始，比较坐标、尺寸、精确包围盒、解析圆/椭圆方程和曲线距离；具体输入、数值与阈值见[验收矩阵](test-accuracy.md)。[`entity_wbtest.mbt`](../entity_wbtest.mbt) 另验证圆心 (10,0)、长轴向量 (10,0)、轴比 0.5 的精确包围盒和平移不变性。

[`geometry_regression_wbtest.mbt`](../geometry_regression_wbtest.mbt) 对未钳制、非均匀节点/有理权重、重节点、五次样条，以 513 个参数点的 de Boor 求值对照生产的 Boehm 节点插入/de Casteljau 离散。它是仓库内另一求值路径，且距离使用现有辅助函数，独立程度低于另写的解析对照；不能描述成外部 ezdxf 实跑或第三方标准套件。具体源码版本由交付标签固定，敏感性记录另保存测试源码哈希。

[故障检出记录](test-sensitivity-results.json)包含实际断言失败与退出码，确认偏移、错误轴向量、样条直线化、bulge 镜像、漏报、误报、净距等值错误、面连接顺序和重复第四点等语义错误能被测试发现。它验证现有测试对列明故障的敏感性，不表示所有错误均能检出。
