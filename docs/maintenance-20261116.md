# 初审后的持续维护记录（2026-11-16）

据参赛者反馈，报名初审已通过。本轮将目标转为可复用DXF基础库的可靠性、许可追溯和可复核边界；不更新报名表，不将初审通过写成最终验收通过，不承诺日期或完整R12符合性。

## 已核对与本轮修改

顾问计划中的读取预算、单遍TagStream、共享几何候选预算、结构警告贯通、端点图、块名索引及Web Worker已在既有源码实现，本轮不重复重构。原实现仍有两处诊断洪泛缺口：单个多段线/样条内部可累计大量坏顶点警告；段分组可在后续结构诊断上限之前累计大量孤立ENDSEC警告。

本轮在上述派生解析循环中补充早停，使用最后一个诊断槽保留资源上限提示，实体轮廓拒绝猜测为Unknown。原始source/records仍可核对；停止后的派生段或几何不能认为完整。该预算按阶段计数，收尾可另有少量诊断，不宣称全图总诊断恒小于1000或保证峰值内存。

新增[公开API安全回归](../maintenance_security_test.mbt)用每类1500条坏坐标/结束标记验证：诊断数量受控、单实体不生成假几何、原始字节/记录保留、最终报告不完整。正常模型另由既有消费者检查；本轮不以“未崩溃”作为唯一断言。

README改为当前维护身份，保留0.2.0未发布、0.1.1已发布、历史r2演示的区分。新增[许可规则](licensing.md)、[模型索引](testing.md)、[兼容性](compatibility.md)、[资源预算](resource-limits.md)及[R12清单](r12-conformance-matrix.md)；旧项目说明/PDF/退回响应保留各自历史背景。许可证文本不变，不创建新的EULA或改变第三方授权。
